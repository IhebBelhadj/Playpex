Server Manager is for whoever runs the server. It finds your Playpex servers on the Wi-Fi and opens the chosen one's dashboard on your phone.

## Opening a server

The app lists the servers it finds on your network, and opens the last one at once when it starts. You can also type an address. Sign in as the server's admin.

To switch servers, press the switch icon at the top of the dashboard.

## What you can do

Everything the dashboard does, sized for a phone:

- **Overview**: downloading, uploading, what's running and how many screens are watching.
- **Library**, **Search** and **Downloads**, with a switch that pauses all downloads.
- **Activity**: what every screen is playing, how far it got, Pause and Stop.
- **Devices**: approve a new screen's pairing code.
- **Profiles**, **Plugins** and **Settings**.

Pull down from the top of a page to reload it.

## The remote

**Remote control** lists the screens you can drive. Press **Control** on one:

- **Touchpad**: drag to move the pointer, tap to click, long press to go back, two fingers to scroll.
- **Arrows**: the arrows, OK and Back.
- Pause and skip back or forward are always at the bottom.

Playpex TV accepts the remote only while its **Settings › Remote control** allows it.

## When the network changes

If the server stops answering (another Wi-Fi, the server restarting), the app says so and tries again by itself, and returns to the page you were on once the server answers.
