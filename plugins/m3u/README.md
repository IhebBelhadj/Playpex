# Live TV (M3U)

A first-party live plugin (`docs/providers-plan.md` §8.4, step 9): the channels of the M3U playlists the admin adds in its settings (a list: as many as they have, up to 20, shown together in its order), each one's programmes from its XMLTV guide (its address, else the one the playlist names: `url-tvg`), a **Live TV** section drawn by the core's `guide` template.

- Carries no list of its own: the admin gives their own IPTV subscription or a public list.
- Its setting `playlists` is a list (plugin API 1.5) of entries `{ name, url, guide, on }`: `url` and `guide` are `url` fields with `grantsHost` (decision J): the host the admin types in each entry joins its network permission (http or https, its port), shown as "Talks to …" on its Permissions. `url` also has `streamHosts`: the hosts of the streams, logos and guide the playlist lists may be streamed from (the admin's document named them). Addresses must be public: a LAN IPTV server can't be reached (yet). "Only these groups" (`groups`) is a list of group names. **2.0** replaced 1.x's five fixed pairs (`playlist` / `guide` … `playlist5` / `guide5`) and the comma-separated `groups`: its `migrate` handler (`contributes.migrate`) carries an admin's values over on the update.
- `live.channels`: `playpex.iptv.m3u(url)` for every playlist that is on, side by side (fetched and parsed by the host, cached 6 h; one that fails is logged and left out) → channels (id: the tvg-id when unique, else a hash of name and group; the other playlists' prefixed `<entry id>:`, so the first one's stay what they were with one playlist; a channel number an earlier playlist took is dropped, the server numbers it after the highest); "Only these groups" filters them all.
- `live.guide`: `playpex.iptv.xmltv(url, { channels, from, to })` per playlist with its own channels (in parallel): matched by tvg-id, else by name.
- `live.stream`: the channel's URL as a `live` source: `.m3u8` → HLS (hls.js in the player), else MPEG-TS (ffmpeg on the server remuxes it). `#EXTVLCOPT:http-user-agent` / `http-referrer` are sent as headers.

Published in the official repository (`~/projects/playpex-plugins/official`). Tested by `apps/server/test/live.test.js`.
